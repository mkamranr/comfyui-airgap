# =============================================================================
#  Custom nodes baked into the air-gapped image
# =============================================================================
#  Format:  <git-url><whitespace><pinned-commit-sha>
#  Blank lines and #-comments are ignored.
#
#  EVERY node MUST carry a pinned SHA. install_custom_nodes.sh treats a missing
#  pin as a fatal build error, because an unpinned HEAD means two builds of the
#  "same" image can contain different code with different runtime download
#  behaviour — which is precisely the class of surprise an air-gapped
#  deployment cannot absorb.
#
#  To add a node:      append the URL, then run ./scripts/pin_custom_nodes.sh
#  To update pins:     ./scripts/pin_custom_nodes.sh --update
#  After ANY change:   rebuild + re-run ./scripts/verify_offline.sh
#
#  SHAs below resolved 2026-09-26.
# =============================================================================
